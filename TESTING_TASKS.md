# Vecchio Restaurant — 5 Usability Testing Tasks

Use these exact five tasks for both the Lo-Fi and Hi-Fi prototype. Do not tell the participant which button to press.

## Task 1 — Access the application
**Scenario:** You are a returning Vecchio Restaurant customer and want to make a reservation.

**Question / task:** Can you log in and reach the main Home screen?

**Hi-Fi completion condition:** Participant logs in successfully and reaches Home.

---

## Task 2 — Check the restaurant menu
**Scenario:** Before booking, you want to see the food choices.

**Question / task:** Can you find the restaurant menu and locate the **Truffle Mushroom Pasta**? Tell the tester its price.

**Hi-Fi completion condition:** Participant opens Menu, finds Truffle Mushroom Pasta, and identifies **RM28**.

---

## Task 3 — Enter reservation details
**Scenario:** You want to reserve dinner for four people and the dinner is a birthday celebration.

**Question / task:** Can you start a new reservation, choose **11 November 2026**, **6:30 PM**, **4 guests**, and add a birthday special request?

**Hi-Fi completion condition:** Participant selects the required date/time/party size, turns on Special Occasion, enters a birthday note, and continues.

---

## Task 4 — Select a suitable table and confirm the reservation
**Scenario:** You need a table that fits four people.

**Question / task:** Can you identify an available table for four people, review all booking information, and successfully confirm the reservation?

**Hi-Fi completion condition:** Participant selects any available table with at least 4 seats (or auto-assign), reaches Review, verifies details, and receives the Reservation Confirmed screen.

---

## Task 5 — Find the completed reservation
**Scenario:** After confirmation, you want to make sure the booking was saved.

**Question / task:** Can you open **My Bookings** and find the reservation you just created? Tell the tester the date, time and table number shown.

**Hi-Fi completion condition:** The newly confirmed reservation is visible in My Bookings with date, time, table, guest count and status.

---

# Recommended measurements for each task

Record:
- Success / Partial Success / Failure
- Time to complete
- Number of wrong taps / navigation errors
- Whether help was required
- Participant comments
- Confidence rating (1–5)

Using the same five tasks in both tests lets you compare Lo-Fi and Hi-Fi task success directly.
